## 1. SQL语法
### 1.1 基础语法
#### 1.1.1 注释
在SQL语句中添加注释，用于解释代码的作用
```sql
-- 这是一条注释
/* 这也是一条注释 */
```

#### 1.1.2 建表
创建数据库中的表
```sql
CREATE TABLE 表名 (
    列1 数据类型 约束,
    列2 数据类型 约束,
    列3 数据类型 约束,
    ...
    -- 主键
    PRIMARY KEY (列1, 列2, ...),
    -- 唯一约束
    UNIQUE (列1, 列2, ...),
    -- 非空约束
    NOT NULL 列1,
    -- 外键约束
    FOREIGN KEY (列1) REFERENCES 表名2(列2),
    -- 检查约束
    CHECK (条件)
);
```

#### 1.1.3 删除表
删除数据库中的表
```sql
DROP TABLE 表名;
```

#### 1.1.4 清空表数据
清空数据库中的表数据，不删除表结构
```sql
TRUNCATE TABLE 表名;
```

```sql
DELETE FROM 表名 WHERE 条件;
```

TRUNCATE 和 DELETE 都可以用来清空数据库中的表数据，但是它们有一些区别：
- TRUNCATE 是一个 DDL 语句，会直接删除表中的所有数据，不记录在日志中，也不触发触发器。
- DELETE 是一个 DML 语句，会删除表中的数据，记录在日志中，也会触发触发器。
- TRUNCATE 操作是原子的，要么全部成功，要么全部失败。
- DELETE 操作可以回滚，但是 TRUNCATE 操作不能回滚。



### 1.2 新增
新增数据到数据库中
```sql
INSERT INTO 表名 (列1, 列2, 列3, ...)
VALUES (值1, 值2, 值3, ...);
```

批量新增数据到数据库中
```sql
INSERT INTO 表名 (列1, 列2, 列3, ...)
VALUES (值1, 值2, 值3, ...),
       (值1, 值2, 值3, ...),
       (值1, 值2, 值3, ...);
```
### 1.3 查询
#### 1.3.1 基础查询
查询数据库中的数据
```sql
SELECT 列1, 列2, 列3, ...
FROM 表名
WHERE 条件;
```
#### 1.3.2 分页查询
分页查询数据库中的数据
```sql
SELECT 列1, 列2, 列3, ...
FROM 表名
WHERE 条件
LIMIT 偏移量, 每页数量;
```
#### 1.3.3 分组查询
分组查询数据库中的数据
```sql
SELECT 列1, 列2, 列3, ...
FROM 表名
WHERE 条件
GROUP BY 列1, 列2, ...
HAVING 分组条件;
```

#### 1.3.4 排序查询
排序查询数据库中的数据
```sql
SELECT 列1, 列2, 列3, ...
FROM 表名
WHERE 条件
ORDER BY 列1 排序方式, 列2 排序方式, ...;
```
排序方式有两种：
- ASC：升序排序（默认）
- DESC：降序排序

### 1.4 更新
#### 1.4.1 单表更新
更新数据库中的数据
```sql
UPDATE 表名
SET 列1 = 值1, 列2 = 值2, ...
WHERE 条件;
```

#### 1.4.2 多表关联更新
更新数据库中的数据，关联其他表中的数据
```sql
UPDATE 表名1
SET 列1 = 值1, 列2 = 值2, ...
FROM 表名2
WHERE 关联条件;
```
#### 1.4.3 merge更新
合并更新数据库中的数据，关联其他表中的数据
```sql
MERGE INTO 表名1
USING 表名2
ON 关联条件
WHEN MATCHED THEN
    UPDATE SET 列1 = 值1, 列2 = 值2, ...
WHEN NOT MATCHED THEN
    INSERT (列1, 列2, 列3, ...)
    VALUES (值1, 值2, 值3, ...);
```

#### 1.4.4 子查询更新
更新数据库中的数据，使用子查询关联其他表中的数据
```sql
UPDATE 表名1
SET 列1 = 值1, 列2 = 值2, ...
WHERE 条件
AND 列3 IN (子查询);
```

#### 1.4.5 FOR UPDATE
锁定数据库中的数据，防止其他事务对其进行修改
```sql
SELECT 列1, 列2, 列3, ...
FROM 表名
WHERE 条件
FOR UPDATE;
```

### 1.5 删除

#### 1.5.1 单表删除
删除数据库中的数据
```sql
DELETE FROM 表名
WHERE 条件;
```

#### 1.5.2 多表关联删除
删除数据库中的数据，关联其他表中的数据
```sql
DELETE FROM 表名1
USING 表名2
WHERE 关联条件;
```

### 1.6 事务
#### 1.6.1 基础事务
开启事务
```sql
START TRANSACTION;
```
提交事务
```sql
COMMIT;
```
回滚事务
```sql
ROLLBACK;
```

### 1.7 索引
#### 1.7.1 基础索引
创建索引
```sql
CREATE INDEX 索引名 ON 表名 (列1, 列2, ...);
```
删除索引
```sql
DROP INDEX 索引名 ON 表名;
```


### 1.8 视图
#### 1.8.1 基础视图
1. 创建视图
```sql
CREATE VIEW 视图名 AS
SELECT 列1, 列2, 列3, ...
FROM 表名
WHERE 条件;
```

2. 查询视图
```sql
SELECT 列1, 列2, 列3, ...
FROM 视图名
WHERE 条件;
```

3. 删除视图
```sql
DROP VIEW 视图名;
```

### 2.6 其他函数
- 字符串拼接函数
```sql

```
- 随机数函数
```sql

```
- 窗口函数
```sql

```

1. 排名函数
```sql
RANK() OVER (PARTITION BY 列名 ORDER BY 列名)
```
2. dense排名函数
```sql
DENSE_RANK() OVER (PARTITION BY 列名 ORDER BY 列名)
```
3. 行号函数
```sql
ROW_NUMBER() OVER (PARTITION BY 列名 ORDER BY 列名)
```
